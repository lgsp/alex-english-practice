Engineering Math: What IS a Function?

Abstract vs. Calculation

La vidéo remet en question la métaphore de la "machine à calculer". Une fonction est avant tout un ensemble de paires (x, y). La "machine" ne calcule pas forcément ; elle cherche simplement la correspondance dans une table de données.

🛠 Engineering Vocabulary

Set vs. Tuple:
  • Set: Order doesn't matter {1, 2} = {2, 1}.
  • Tuple: Order matters (1, 2) ≠ (2, 1).
Relation Properties:
  • Left total: Every X has a Y.
  • Right unique: Every X has at most one Y.

Knowledge Check

1. In mathematics, what do we call a "set of pairs"?

  • A calculation rule

  • A Cartesian machine

2. What is the main difference between a Set and a Tuple?

  • The order of elements matters in a tuple.
  • A set uses round brackets.
  • They are exactly the same thing.
