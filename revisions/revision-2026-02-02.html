Abstract vs. Calculation

What IS a Function?

🔢 Mathematical Logic (Functions)

In mathematics, a function is not just a calculation; it is simply a set of pairs.

Punctuation & Sets:
  • { } : Curly brackets (used for Sets)
  • [ ] : Square brackets
  • ( ) : Round brackets (Parentheses)
Connectors:
  • Hence / Thus : Ainsi / Par conséquent.
  • Therefore : C'est pourquoi.
  • For instance : Par exemple.

🛠 Tools & Workshop Lexicon
